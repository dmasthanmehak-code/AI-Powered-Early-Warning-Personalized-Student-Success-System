# AI-Powered Early Warning & Personalized Student Success System

## About the Project
This project helps identify students who may need additional
academic support by analyzing attendance, marks, and assignment completion.

## Features
- Student performance analysis
- Early academic risk warnings
- Personalized learning recommendations
- Interactive student dashboard

## Technologies
- Python
- Streamlit
- Pandas

## How to Run
1. Install Python.
2. Install dependencies using:
   pip install -r requirements.txt
3. Run the application using:
   streamlit run app.py

## Goal
Help teachers identify learning difficulties early and provide
timely support to improve student outcomes.
